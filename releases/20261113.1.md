## Changes

- perf: cut iOS memory, offscreen rendering and mount cost found with the shop benchmark (#843) (5db9b180)
- fix: keep the iOS edge swipe working when its target unmounts, and stop it scrolling the screen (#842) (2b6493bd)
- fix(whisker-webview): reject mixed content on Android (#823) (a7be9c0b)
- fix(whisker-macros): count spread roots in layout route paths (#838) (6b947214)
- fix(whisker-secure-store): reject the Android keyset reserved key (#822) (1e2b54ae)
- fix(whisker-cng): pin Gradle distribution integrity (#818) (9501720b)
- fix(whisker-cli): exclude credentials from rustc environment capture (#811) (5e95d863)
- fix(whisker-submit): constrain service account token exchanges (#808) (1a45c944)
- feat(cli): add `whisker run windows` with Hot Reload (#837) (101009b4)
- feat(cli): add `whisker run linux` with Hot Reload (#836) (07e328ce)
- perf(dev-server): build hot-reload patches with multiple codegen units (#835) (05ebfe16)
